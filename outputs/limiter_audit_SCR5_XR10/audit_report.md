### Limiter rule and location

`InnerCtrl_i_conv_max=1.2` feeds the cascaded controller's `i_conv_limit`, then the dq limiter's `X_dq_max`. `limType=Constant ratio d/q`; the abc alternative is inactive. The limiter is enabled on the selected control path. Whether its active flag is true at a particular EMT instant requires the PI state/reference at that instant; no such time snapshot is claimed here.

For raw voltage-controller output r=[r_d,r_q],

    s = r                         if ||r|| <= 1.2
    s = 1.2 r / ||r||             if ||r|| > 1.2
    a_I = (||r|| > 1.2).

This limits the **converter/filter-inductor current reference**, not measured current itself, capacitor-branch current, or grid current. It preserves dq-reference direction. There is no selected d/q clipping, active/reactive priority, variable virtual impedance or hysteresis in this limiter. `OuterCtrl_Lvirt=0`; active damping 0.2 is not a SatLim back-calculation impedance Z_vi. Finite-bandwidth physical current can overshoot its limited reference.

In the normal VSM mode, define measured positive-sequence capacitor voltage v_c, converter current i_c, and LV filter output current i_f. With J2=[0,-1;1,0]:

    e_v = v* - v_c
    r   = 0.8 e_v + xi_v + i_f + nu*0.04569*J2*v_c
    s   = sat_radial(r,1.2)
    e_i = s - i_c
    u   = 3.3 e_i + xi_i + v_c + nu*0.05097*J2*i_c
    w   = sat_radial(u,1.3)
    v_bridge_command = w - 0.2*i_conv,dq0.

The two feedforward paths are enabled; command-derivative feedforwards are disabled. The voltage loop controls the physical capacitor node through its measured voltage. In normal mode Lvirt=0 gives v*=[Vouter,0]. Vouter is generated by Q-V control: v_set plus a filtered 0.1(q_set-q_grid), TQ=0.2 s. It is not generally a fixed-amplitude physical source during saturation. Mode selection also affects angle/reference and freeze; normal grid-forming operation is the scope of the proposed reduction.

### Anti-windup and state memory

For each axis a=d,q, with a_V=(||u||>1.3):

    F_va[k] = F_force[k] OR (a_I[k-1] AND sign(r_a[k-1])==sign(e_va[k-1]))
    F_ia[k] = F_force[k] OR (a_V[k-1] AND sign(u_a[k-1])==sign(e_ia[k-1]))
    xi_va[k+1] = xi_va[k] + Ts*0.5 *(1-F_va[k])*e_va[k]
    xi_ia[k+1] = xi_ia[k] + Ts*16.5*(1-F_ia[k])*e_ia[k].

These are Forward-Euler updates away from reset events. F_force=1 for modes -1 and 1; 0 for modes 0 and 2. Rising reset sets the relevant integrators to zero. During freeze the proportional term remains active. PID internal anti-windup is `none`: the external conditional integration implements anti-windup. Activation and sign-comparison paths have parallel one-sample delays, not two serial delays. The radial current-reference output itself is not delayed by that activation delay. No separate release threshold/hysteresis was found; release and reference direction depend on PI memory and delayed freeze logic.

From the baseline linear nodal coefficients:

    I_conv = icE*V_c + icU*U = (V_c - Vth)/Zeq
    I_shunt = Yc*V_c
    I_filter_grid = I_conv - I_shunt
    I_grid = igE*V_c + igU*U
    V_grid = vgE*V_c + vgU*U

Thus the baseline capacitor-port injection is precisely the converter-inductor current in the quasi-steady network, including shunt demand. It is not grid current. Converter RL need not be added to downstream Zeq to calculate this current from a prescribed capacitor voltage.     V_bridge_required = V_c + Z_f*I_conv
    u_required = V_bridge_required + 0.2*I_conv

(the latter uses ideal fundamental dq0/dq+ agreement). Do not double-count Z_f by adding it to Zeq while retaining capacitor voltage as the prescribed source.

## 4. Recommended next analytical approximation (explicit assumptions)

For continuity with the two-state baseline, implement a **network-consistent ideal radial-current benchmark**, not an exact reduction of the PI/freeze controller. Assume ideal current tracking, constant voltage target E, balanced quasi-steady network at 50 Hz, unity measurement approximation and no voltage saturation within the model's claimed validity domain. PI memory and release dynamics are omitted. In saturation gamma denotes the VSM **target angle**, not the actual capacitor voltage angle.

Let phi=arg(Vth), U be the baseline actual referred physical bus magnitude, Vth=tU with constant complex t, and

    V_target = E exp(j(gamma+phi))
    q = (V_target - tU)/Zeq
    h = |q|-1.2.

Unsaturated branch h<=0:

    I_conv=q; V_c=V_target.

Saturated branch h>0:

    I_conv=1.2*q/|q|; V_c=tU+Zeq*I_conv.

On BOTH branches reconstruct transformer nodes, grid current and grid voltage using the unchanged nodal coefficients above; then Pe=Re(V_grid conj(I_grid)). Calculate V_bridge and u_required using Z_f. If |u_required|>1.3, this current-only idealization is outside its declared voltage-capability assumptions; do not silently assume ideal current tracking there. Combining current and voltage saturation requires a further closure/controller model.

The two branches match at h=0 and the unsaturated equations recover the current baseline exactly. The direction q is an **assumed proxy** for the raw PI reference r; direction preservation by the real limiter does not prove r=q. No hidden equality between measured current and a clipped reference is claimed.

Keep the two baseline dynamics and tuning:

    gamma_dot=nu-1
    nu_dot=((Pstar-Pe)/nu-25*(nu-1))/6.8.

### Derivatives and contraction

On each open smooth branch use its actual network-reconstructed Pe. In real dq coordinates the derivative of radial projection is I on the inactive branch and (1.2/|q|)(I-q q^T/|q|^2) on the active branch. q_gamma=j V_target/Zeq and q_U=-t/Zeq. Propagate these through V_c, V_grid and I_grid. For z=gamma or U:

    Pe_z = Re(V_grid,z conj(I_grid) + V_grid conj(I_grid,z)).

Differentiate again on the same branch for Pe_gammaU; retain both voltage and current derivative terms. At equilibrium construct beta=-Pe_U/6.8, c=-Pe_gammaU/6.8 and Theta=[-beta,0;-c,-beta] using the existing convention. Exclude singular Theta and explicitly test M=Theta^T Theta. Use the correct Pe_gamma and off-equilibrium Pe in J. For a fixed reference metric, Theta_dot=0; if a metric is changed with state or branch, its derivative/jump cannot be omitted. Do not transplant old saturated derivatives or claim a state-dependent branch metric is the original fixed metric.

At h=0 use one-sided Jacobians. Smooth-branch negativity alone is not a switched-system certificate. A common continuous metric with suitable generalized-Jacobian bounds on both sides and a forward-invariant domain, or an explicit transition analysis, is needed. For this continuous ideal vector field and transversal identity-state crossings the saltation matrix is identity; this does not rescue incompatible metrics or establish global contraction. Actual delayed freeze/reset logic requires its own hybrid/discrete transition analysis.

## 5. Unresolved controller fidelity and final recommendation

The actual controller cannot in general be closed with gamma and nu alone: identical gamma/nu can have different xi_v, xi_i, raw current directions and release behavior. A controller-faithful candidate retains at least the four PI integrator states in addition to gamma/nu, with the nodal algebraic network and Z_f bridge relation; Q-V, PLL, measurement filters and delay memories add further states when retained. This is a six-state DAE *core*, not a proven exact minimum. Differential-algebraic derivatives require a locally unique algebraic solution: Jred=f_x-f_z g_z^{-1}g_x. Saturation/freeze modes and resets remain explicit.

No saved full controller operating-point snapshot was supplied. Exact PI initial states, actual transient overshoot and release timing therefore remain unverified; configured blocks/equations are verified. The baseline's normalized analytical time is also an assumption: actual VSM relative angle in physical seconds has 2*pi*50*(nu-1). Do not append SI PI dynamics to the normalized baseline without consistently resolving the time convention across all equations.

**Recommendation:** next implement only the explicit two-state ideal radial-current benchmark above, with capacitor-voltage reconstruction, correct grid power and a voltage-capability validity check. Label it as an analytical assumption and discard infeasible R1/R2 operating points before selecting limited equilibria. If the intended claim is reproduction of the saved controller's saturation/release or anti-windup, use the controller-state model instead; a two-state projection is insufficient. Neither implementation nor sweeps were started in this audit.
